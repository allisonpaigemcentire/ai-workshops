r15-ios-cx: Fleet View Setup

Quick reference

Repo: r15-ios-cx (iOS app, Swift/SwiftUI)

Branch naming: <username>/TYP-XXXXX (same as web)

Worktree pattern: Spec-driven. .spec/work/<TICKET>/ directory is worktree-local (not shared)

Important: Create branch from origin/dev with --no-track

Standard worktree (outside spec flow)

1. Create branch from origin/dev
git worktree add -b am/TYP-12345/feature-name \ ../r15-ios-cx-TYP-12345 origin/dev

Omit --no-track if you want the branch tied to local dev state. Include it if you want a fresh checkout.

2. Verify Xcode and dependencies

No special files to copy. Xcode project (.xcworkspace) and Pod dependencies come automatically.

Exact steps: Claude CLI (standard flow)

claude --worktree task-1 "Create branch am/TYP-12345-a from origin/dev. Then [task 1 on feature]. Commit and push." & claude --worktree task-2 "Create branch am/TYP-12346-b from origin/dev. Then [task 2 on feature]. Commit and push." & wait

Track results

gh pr list --author=@me git worktree list

Notes

  • Sibling paths: Worktrees live as siblings: ../r15-ios-cx-TYP-12345, not under .claude/worktrees/.
  • Xcode: .xcworkspace and Pod dependencies are tracked; they come automatically in each worktree.
