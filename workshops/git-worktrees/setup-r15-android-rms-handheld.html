r15-android-rms-handheld: Fleet View Setup

Quick reference

Repo: r15-android-rms-handheld (Android app, Kotlin)

Branch naming: <initials>/ticket/topic

Per-worktree setup: Create local.properties; keystores are tracked (come automatically)

Prerequisites: Java 17 (SDKMan), Android SDK

Per-worktree setup checklist

Create local.properties (git-ignored):
sdk.dir=/Users/amcentire/Library/Android/sdk

Adjust the path based on your Android SDK location. Or copy from main checkout if it exists.

Keystores (already tracked in git):

These come automatically. No copying needed:

  • app/handheldDebug.keystore
  • app/handheldRelease.keystore
  • watch/watchDebug.keystore
  • watch/watch-rms.keystore

Exact steps: Claude CLI

claude --worktree task-1 "Create local.properties with sdk.dir=/Users/amcentire/Library/Android/sdk. Then [task 1 on handheld or watch code]. Commit and push to am/task-1-xxx." & claude --worktree task-2 "Create local.properties with sdk.dir=/Users/amcentire/Library/Android/sdk. Then [task 2]. Commit and push to am/task-2-xxx." & claude --worktree task-3 "Create local.properties with sdk.dir=/Users/amcentire/Library/Android/sdk. Then [task 3]. Commit and push to am/task-3-xxx." & wait

Track results

gh pr list --author=@me git worktree list

Notes

  • local.properties is not tracked — you must create it in each worktree or copy from main.
  • Keystores are committed to the repo, so they come automatically.
  • Android Studio and Gradle sync are optional for pure code edits; not required for all tasks.
  • Java 17 must be active: sdk use java 17.0.1-temurin (or your Java version).
