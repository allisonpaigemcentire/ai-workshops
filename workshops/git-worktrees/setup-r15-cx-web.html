r15-cx-web: Fleet View Setup

Quick reference

Repo: r15-cx-web (Next.js web app)

Branch naming: am/TYP-XXXXX or am/no-ticket/<kebab>

Per-worktree setup: npm install (node_modules not shared)

.env: Tracked in git (comes automatically)

Exact steps: Claude CLI

1. Start in the main checkout
cd /Users/amcentire/r15-web-cx
2. Pre-setup: Run npm install in each worktree
cd /Users/amcentire/.claude/worktrees/task-1 && npm install cd /Users/amcentire/.claude/worktrees/task-2 && npm install cd /Users/amcentire/.claude/worktrees/task-3 && npm install

OR skip this and embed "run npm install" in each prompt (step 3).

3. Launch three claude processes in parallel
claude --worktree task-1 "Run npm install. Then [your task 1]. Commit to branch am/no-ticket/task-1-xxx. Push and open a PR." & claude --worktree task-2 "Run npm install. Then [your task 2]. Commit to branch am/no-ticket/task-2-xxx. Push and open a PR." & claude --worktree task-3 "Run npm install. Then [your task 3]. Commit to branch am/no-ticket/task-3-xxx. Push and open a PR." & wait
4. Track the results
gh pr list --author=@me gh pr checks <pr-number> git worktree list

Exact steps: Claude Code (IDE)

  1. Open the repo in Claude Code.
  2. In the chat, spawn 3 agents in one message with isolation: "worktree" on each.
  3. Give each agent a task and instructions to: run npm install first, then complete the task, then commit and push to a named branch.
  4. Agents run in parallel; track with gh pr list.

Exact steps: Cursor

  1. Open the repo in Cursor.
  2. Use /worktree task-1 "prompt". The prompt should include: run npm install, do the task, commit and push.
  3. When complete, use /apply-worktree to bring changes to main.
  4. Repeat with /worktree task-2 and /worktree task-3.
  5. Track with gh pr list.

Notes

  • .env is tracked in git, so it comes automatically in each worktree.
  • node_modules/ is NOT shared — npm install must run in each worktree.
  • If you skip pre-setup in step 2, instruct Claude/Cursor to run npm install as the first step of their task.
