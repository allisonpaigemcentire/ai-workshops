Git Worktrees Cheat Sheet

Essential Commands

git worktree list git worktree add -b <branch> <path> <commit-or-branch> git worktree add <path> <branch> git worktree add --detach <path> <commit> git worktree remove <path> git worktree prune

Common Tasks

Task Command
Create and check out a new branch git worktree add -b feature/foo ../repo-foo origin/dev
Create from an existing branch git worktree add ../repo-feature feature/bar
Create a detached (throwaway) checkout git worktree add --detach ../repo-scratch HEAD
List all worktrees git worktree list
Remove a worktree git worktree remove ../repo-foo
Remove stale metadata git worktree prune

Key Rules

  • One branch per worktree. Git blocks the same branch from being checked out in two worktrees.
  • List before you create. Run git worktree list to see what paths and branches already exist.
  • Remove with Git. Use git worktree remove, not manual directory deletion. If a directory was deleted by hand, run git worktree prune.

Claude Code

claude --worktree feature-auth claude --worktree "#42" claude --worktree "https://github.com/org/repo/pull/42"

Claude Code creates .claude/worktrees/<name>/ and branch worktree-<name>. Use .worktreeinclude to copy chosen gitignored files like .env.

Cursor

  • /worktree <task> — run the rest of the chat in a worktree
  • /best-of-n model1,model2 <task> — parallel candidates; compares, does not merge
  • /apply-worktree — bring selected worktree changes into the main checkout
  • /delete-worktree — remove the isolated checkout
