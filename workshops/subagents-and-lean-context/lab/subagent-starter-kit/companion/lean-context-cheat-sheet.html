Subagents and lean context for Cursor and Claude Code

Three read-only subagents do the reading in their own context and send back a short answer. Your main chat keeps the decisions. A fresh chat per task and short always-on files keep answers sharp.

Supported tools: Cursor, Claude Code
Kit: subagent-starter-kit

1Install, check, undo

mkdir -p ~/src && unzip ~/Downloads/subagent-starter-kit.zip -d ~/src
bash ~/src/subagent-starter-kit/install.sh --dry-run
bash ~/src/subagent-starter-kit/install.sh
bash ~/src/subagent-starter-kit/install.sh --check
bash ~/.subagent-starter-kit/uninstall.sh
  • Copies code-reader, doc-reader and context-checker into ~/.claude/agents/ and ~/.cursor/agents/. Nothing else.
  • A same-name file that is yours is left alone. --force replaces it after a backup; uninstall puts it back.
  • One tool only: --tools=cursor or --tools=claude.
  • Claude Code: restart once if ~/.claude/agents/ is new. Cursor: if an agent does not show yet, start a new chat.

2Use them

Either"Use the doc-reader subagent to ..." lets the main agent decide

Write the task like a ticket: goal, paths to read, limits, and the shape of the answer. Open one cited path:line before you act on it.

3Maintain and audit

  • The description decides routing. Say what it does and when; "use proactively" invites delegation.
  • Claude Code picks up edits in ~/.claude/agents/ within a few seconds.
  • Keep two or three focused agents. Five in parallel cost about five times the tokens of one.
  • install.sh --check reports ok, DRIFT, yours and LINT for every agent file.
  • Claude Code skips a file with no name, no description, --- not on line 1, or bad YAML, and says nothing. Full parse: claude plugin validate ~/.claude/agents (v2.1.233 or later).
  • Audit prompt: prompts/audit-subagents.md. It returns a ranked shortlist and changes nothing until you pick.

4Why long sessions get worse

  • More tokens, weaker recall: "a performance gradient rather than a hard cliff" (Anthropic).
  • Length alone hurts across 18 models; a focused 300-token prompt beat the full 113k-token history (Chroma).
  • Early evidence, 2023 models: facts in the middle of a long input are found least often (Liu et al.).
  • A wrong turn sticks: the same task split over many turns did 39% worse on average (Laban et al.).
  • Summaries lose detail: early instructions "may be lost" after compaction (Claude Code docs).

6What fills your context

  • Always-on rules, CLAUDE.md, AGENTS.md: every session. Keep them short and scope the rest.
  • MCP servers: tool names and instructions, even unused. Turn off what you do not need.
  • File reads and tool output: name the file; send wide searches to a subagent.
  • The conversation: all of it, on every request.
